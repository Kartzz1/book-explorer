# Book Explorer

A digital library built with React and Open Library.

## Features

- Home, Explore, Favorites, and About pages
- Book details page
- Search books using Open Library
- Browse books by category
- Save favorite books
- Favorites saved with localStorage
- Dark Mode and Night Mode
- Responsive design
- Interactive book UI
- Loading, error, and empty states
- Open Library reading and book links when available

## Run Locally

npm install
npm run dev
